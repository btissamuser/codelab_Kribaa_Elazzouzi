Cours CSS

CSS (Cascading Style Sheets) décide de l'apparence de ta page : couleurs, tailles, espacements et mise en page.

1. Sélecteurs

Une règle CSS = un sélecteur (qui ?) + des déclarations (quoi ?). On relie le fichier CSS dans le <head> avec <link rel="stylesheet" href="css/style.css">.

p { color: #333; }              /* toutes les balises <p> */
.carte { padding: 20px; }       /* les éléments class="carte" */
#menu { background: black; }    /* l'élément id="menu" (unique) */
nav a { text-decoration: none; }/* les <a> à l'intérieur de <nav> */
a:hover { color: purple; }      /* pseudo-classe : au survol */

2. Couleurs et polices

Une couleur peut s'écrire avec un nom (red), en hexadécimal (#e34c26), en rgb() ou en hsl(). Les variables CSS évitent de répéter les mêmes valeurs.

:root {
  --principale: #7c3aed;
}
body {
  font-family: "Segoe UI", Arial, sans-serif;
  font-size: 16px;
  line-height: 1.6;
  color: #1d1d2b;
}
h1 { color: var(--principale); }

5. Responsive design

Un site responsive s'adapte à toutes les tailles d'écran. Deux ingrédients : la balise meta viewport dans le HTML et les media queries dans le CSS.

<meta name="viewport" content="width=device-width, initial-scale=1">

/* Ordinateur : 3 colonnes */
.grille { display: grid; grid-template-columns: repeat(3, 1fr); }

/* Écran de moins de 640px : 1 seule colonne */
@media (max-width: 640px) {
  .grille { grid-template-columns: 1fr; }
}

💡 Teste-le ici même : réduis la largeur de ta fenêtre, le menu se transforme en bouton ☰ et les colonnes passent les unes sous les autres.

6. Transitions et animations

transition anime le passage d'un état à un autre (au survol par exemple). @keyframes crée une animation en plusieurs étapes. Survole le bouton ci-dessous :

Survole-moi

.btn { transition: transform 0.2s; }
.btn:hover { transform: translateY(-2px); }

@keyframes flotter {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-14px); }
}
.image { animation: flotter 4s ease-in-out infinite; }
