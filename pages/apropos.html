À propos de CodeLab

CodeLab est un projet réalisé dans le cadre du module Programmation Web 1 (TI504N) à l'EFREI Paris, en HTML5, CSS3 et JavaScript, sans aucun framework ni bibliothèque.

L'équipe

BK

Btissam KRIBAA

HTML CSS JS

Maquette du site, page d'accueil (carrousel, compteurs animés), cours HTML et CSS, simulateurs du modèle de boîte et de Flexbox, design responsive.

AE

Ayoub EL AZZOUZI

JS CSS

Cours JavaScript, console et éditeur en direct, quiz chargé en JSON avec fetch, tableau des scores, formulaire de contact et validation.

Le projet en bref

🎯 Objectif

Proposer un site simple et interactif pour apprendre les trois langages du Web, pensé pour les grands débutants.

🛠️ Technologies

HTML5 sémantique, CSS3 (variables, Grid, Flexbox, media queries, animations) et JavaScript natif (DOM, événements, fetch, localStorage).

✅ Qualité

Pages validées avec le validateur W3C, site responsive (mobile, tablette, ordinateur) et versionné avec Git.
