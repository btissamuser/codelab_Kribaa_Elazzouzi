Cours JavaScript

JavaScript est le langage de programmation du navigateur : il rend tes pages interactives.

1. Variables et types

On déclare une variable avec let (modifiable) ou const (non réaffectable). On évite l'ancien var.

const prenom = "Btissam";   // chaîne de caractères (string)
let age = 20;               // nombre (number)
let estEtudiant = true;     // booléen (boolean)
const langages = ["HTML", "CSS", "JS"];        // tableau
const cours = { nom: "Web", heures: 30 };      // objet

age = age + 1;
console.log(`${prenom} a ${age} ans`);         // template string

2. Conditions et boucles

const note = 14;
if (note >= 16) {
  console.log("Très bien");
} else if (note >= 10) {
  console.log("Validé");
} else {
  console.log("Rattrapage");
}

for (let i = 1; i <= 3; i++) {
  console.log("Tour n°" + i);
}

["HTML", "CSS", "JS"].forEach((langage) => console.log(langage));

💡 Utilise toujours === (égalité stricte) plutôt que == : "5" == 5 vaut true mais "5" === 5 vaut false.

3. Fonctions

Une fonction regroupe des instructions réutilisables. Elle peut recevoir des paramètres et renvoyer une valeur avec return.

function moyenne(a, b) {
  return (a + b) / 2;
}

// la même chose en fonction fléchée
const carre = (x) => x * x;

console.log(moyenne(12, 16)); // 14
console.log(carre(5));        // 25

4. DOM et événements

Le DOM est la représentation de la page que JavaScript peut lire et modifier. On sélectionne un élément puis on écoute un événement (clic, saisie, envoi…).

const bouton = document.querySelector("#demo-click");
const compteur = document.querySelector("#demo-count");
let clics = 0;

bouton.addEventListener("click", () => {
  clics++;
  compteur.textContent = clics;
});

Essaie : — nombre de clics : 0

5. Asynchrone et gestion des erreurs

Certaines actions prennent du temps (charger un fichier, appeler une API). Avec async / await, on attend le résultat sans bloquer la page, et try / catch attrape les erreurs pour que le site continue de fonctionner.

async function chargerQuestions() {
  try {
    const reponse = await fetch("../data/quiz.json");
    if (!reponse.ok) throw new Error("Erreur " + reponse.status);
    const questions = await reponse.json();
    console.log(questions.length + " questions chargées");
  } catch (erreur) {
    console.error("Chargement impossible :", erreur.message);
  }
}
chargerQuestions();

💡 C'est exactement ce que fait la page Quiz ! Et l'attribut defer sur <script> permet au navigateur d'afficher le HTML avant d'exécuter le script.
