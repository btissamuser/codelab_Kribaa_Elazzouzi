Cours HTML

HTML (HyperText Markup Language) sert à décrire le contenu d'une page Web à l'aide de balises.

1. Structure d'une page

Toute page HTML5 commence par le <!DOCTYPE html>, puis la balise <html> qui contient deux parties : le <head> (informations pour le navigateur) et le <body> (ce qui s'affiche).

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Ma première page</title>
</head>
<body>
  <header>...</header>
  <main>...</main>
  <footer>...</footer>
</body>
</html>

💡 Les balises <header>, <nav>, <main>, <section>, <article> et <footer> sont dites sémantiques : elles donnent du sens au contenu (utile pour le référencement et l'accessibilité).

2. Titres et textes

Il existe six niveaux de titres, de <h1> (le plus important, un seul par page) à <h6>. Les paragraphes s'écrivent avec <p>.

<h1>Titre principal</h1>
<h2>Sous-titre</h2>
<p>Un paragraphe avec un mot <strong>important</strong>
et un mot <em>mis en valeur</em>.</p>
<br> <!-- retour à la ligne -->

3. Liens et images

Un lien utilise la balise <a> et l'attribut href. Une image utilise <img> avec src (le chemin) et alt (le texte alternatif, obligatoire).

<a href="pages/css.html">Lien vers une autre page</a>
<a href="https://developer.mozilla.org" target="_blank">Site externe</a>
<a href="#tableaux">Aller à une section de la page</a>

<img src="img/logo.svg" alt="Logo de CodeLab" width="64" height="64">

💡 Chemin relatif (../img/logo.svg) = à partir du fichier actuel. Chemin absolu = adresse complète commençant par https://.

4. Listes

<ul> crée une liste à puces, <ol> une liste numérotée. Chaque élément est un <li>.

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<ol>
  <li>Écrire le HTML</li>
  <li>Ajouter le CSS</li>
</ol>

5. Tableaux

Un tableau se construit ligne par ligne avec <tr>. Les cellules d'en-tête sont des <th> et les cellules normales des <td>. Voici un tableau récapitulatif des balises vues :

  </thead>

6. Formulaires

Un formulaire regroupe des champs dans <form>. Chaque champ <input> doit être relié à un <label> grâce aux attributs for et id.

<form action="#" method="post">
  <label for="prenom">Prénom</label>
  <input type="text" id="prenom" name="prenom" required>

  <label for="mail">E-mail</label>
  <input type="email" id="mail" name="mail">

  <button type="submit">Envoyer</button>
</form>

Types d'<input> utiles : text, email, password, number, date, checkbox, radio, range. Un vrai formulaire validé en JavaScript t'attend sur la page Contact.
